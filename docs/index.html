Codex plugin · MCP server · local-first

Spend context on the task, not on repetition.

Capsule is an exact-recoverable token-efficiency and context-compression layer for Codex. It shows the model the smallest safe evidence view, while keeping the complete local result available on demand.

Install Capsule Read measured results

Terminal and files

Compresses repetitive stdout, bounded file reads, and safe Get-Content calls without hiding failures or exact recovery.

Projects and memory

Compiles symbols, dependency impact, durable facts, and context handoffs before the model rereads an entire codebase.

Web and tools

Keeps structured results, URLs, and references recoverable while limiting repeated catalog and page payloads.

Conservative by design

Token-negative, unsafe, failed, literal, or explicitly full requests pass through unchanged.

How it works

Every result follows a simple local pipeline:

request → classify → compact evidence view
                    ↘ exact local capsule → expand on demand

Capsule's published A/B figures are workload-specific model-visible measurements, not a promise about hidden reasoning, provider caching, billing, or subscription quotas.

Open source and verifiable

Read the implementation, tests, release history, privacy contract, and reproducible benchmarks in the public repository. Contributions and security reports are welcome.
